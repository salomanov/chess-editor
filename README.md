# Редактор позиций

Статический сайт для редактирования Excel-файла вида `Номер / Позиция / ход`.

## Запуск

```bash
npm install
npm run dev
```

## Сборка для хостинга

```bash
npm run build
```

Готовые файлы окажутся в `dist/`. Приложение работает полностью в браузере:
- загружает `.xlsx` через кнопку выбора файла;
- показывает список позиций;
- позволяет менять порядок записей;
- открывает выбранную позицию на доске;
- дает двигать фигуры, добавлять новые записи и сохранять обновленный `.xlsx`.
